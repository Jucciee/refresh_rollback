# Refresh Rollback (F5 새로고침 복구기)

웹 서핑 중 실수로 `F5`나 `새로고침`을 눌러서 작성 중인 폼 데이터나 보고 있던 유튜브 피드가 날아가는 것을 방지해주는 크롬 브라우저 확장 프로그램입니다.

## 🚀 주요 기능

1. **자동 상태 백업**: `F5`, `Ctrl+R`, `Cmd+R`을 누르는 순간, 브라우저가 페이지를 새로고침하기 직전에 화면 전체(DOM 구조), 스크롤 위치, 입력 중이던 텍스트(input, textarea) 값을 자동으로 저장합니다.
2. **유튜브 피드 완벽 복원**: 새로고침 시 무작위로 섞여버리는 유튜브 홈 화면의 영상 피드를 원래 보고 있던 상태 그대로 복원합니다.
3. **간편한 단축키 지원**: `Alt+R` 키를 누르면 가장 최근에 백업된 상태로 즉시 화면을 되돌립니다.
4. **'돌아가기 전 State' (실행 취소)**: 과거의 상태로 복구를 진행할 때, 복구하기 직전의 현재 화면 상태를 임시로 저장해 둡니다. 복구한 화면이 마음에 들지 않으면 즉시 방금 전으로 되돌릴 수 있습니다.
5. **새 탭에서 열기**: 저장된 과거 상태를 현재 탭을 덮어쓰지 않고 '새 탭'으로 열어서 화면을 유지할 수 있습니다.
6. **사이트 필터링 (옵션)**: 특정 사이트에서만 작동하게 하거나(화이트리스트), 특정 사이트에서만 작동을 끌 수 있습니다(블랙리스트).

---

## ⚠️ 상태 복구(State 변경) 시 주의사항

이 확장 프로그램은 브라우저에 표시된 **HTML 화면 뼈대(DOM)를 통째로 캡처하여 강제로 덮어씌우는 방식**으로 화면을 복구합니다. 따라서 다음과 같은 태생적인 한계가 존재하므로 반드시 유의해 주세요.

* **버튼 및 상호작용 먹통 현상**: React, Vue 등 최신 기술로 만들어진 웹사이트(SPA)의 경우, 화면을 강제로 과거 HTML로 되돌리면 내부에 연결되어 있던 자바스크립트 이벤트(클릭, 호버 기능 등)가 끊어져 **버튼을 눌러도 반응하지 않거나 에러가 날 수 있습니다.**
* **시각적 복구(읽기 전용) 권장**: 상태 복구 기능은 가급적 **'입력 중이던 텍스트 내용을 다시 복사하기 위해'** 또는 **'아까 띄워져 있던 유튜브 썸네일과 제목을 다시 찾기 위해'**와 같이 **시각적인 확인 및 읽기 용도**로 사용하시는 것을 강력히 권장합니다.
* **유튜브 관련 제약**: 유튜브 피드를 복구한 경우, 영상 썸네일을 클릭해서 시청하러 가거나 휠(가운데 버튼) 클릭으로 새 탭에서 여는 것은 정상 작동합니다. 그러나 썸네일에 마우스를 올렸을 때 나타나는 자동 미리보기 재생이나 '나중에 볼 영상 추가' 등의 복잡한 메뉴 버튼은 작동하지 않습니다.

## ⚙️ 설치 방법

1. 크롬 브라우저 주소창에 `chrome://extensions/`를 입력하여 확장 프로그램 관리 페이지로 접속합니다.
2. 우측 상단의 **[개발자 모드]** 스위치를 켭니다.
3. 좌측 상단에 나타난 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
4. 이 `README.md` 파일이 들어있는 폴더(`refresh_rollback`)를 통째로 선택합니다.
5. 설치가 완료되었습니다! 브라우저 우측 상단의 퍼즐 모양 아이콘을 눌러 확장 프로그램을 고정(Pin)해두고 편리하게 사용하세요.
